## 深港 IX 到底是什么线路

IX 指互联网交换中心（IXP）。Mkcloud 的深港 IX 专线，全称“深港上云互联优化专线”，接的是国家（深圳·前海）新型互联网交换中心（CNIX）。它的工作方式和常见专线不太一样：

- 流量从云厂商的机器通过**云厂内网**进入交换中心，再经专线落到香港，从**香港 BGP 出口**向外访问；
- 因为走的是交换中心内网，入口没有公网路由，天然规避了公网扫描和大部分 DDoS 直接攻击面；
- 官方给出的端内延迟参考是 **1~2ms**，这是深圳到香港段内的参考值，不是你本地到目标网站的全程耗时。

和 IEPL、IPLC 的关键差异在接入方式：IEPL/IPLC 是直连型线路，绑定一个连入省份；IX 不限绑定省份，但要求你有一台**受支持的云厂商前置机**，通过云厂内网接入。这个前置要求是深港 IX 最大的门槛，后面单独算账。

## 前置机：深港 IX 的隐藏成本

深港 IX 的套餐价格只是账单的一半，另一半在前置机上。

**支持范围**：深圳入口目前支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云华南，具体以购物车说明为准。前置机通过云厂内网把流量送进交换中心，不走公网。

**成本差异很大**。独立博主 catcat.blog 在 2026 年初的实测中提到几个关键点：阿里云、腾讯云的轻量实例是性价比较高的前置方案（标称 200M 带宽），但带宽没有强保证，已经有实例被限速到 20M 甚至 1M 的案例；火山云延迟表现更好，但没有轻量实例形态，按量计费的流量成本约 0.8 元/GB，长期跑会不便宜。该博主的测试环境用的是火山引擎 2G 带宽 ECS，机器 550 元/年，共享流量包 437 元/T/年。

另一个风险是云厂政策变动。Mkcloud 官方通知群曾公告阿里云与火山对前海 IX 方向进行单方面整改，期间通过这两家访问的深圳 IX 受到影响。这类事件不是服务商能控制的，但会直接打在你的业务上，所以：

把前置机月成本加进套餐价再算总账，深港 IX 才是“真实的便宜”。如果算完总成本已经接近广港 IEPL，而你的接入环境又不在云上，直连款反而是更简单的答案。

## 什么业务适合，什么业务别碰

深港 IX 交付的是 VPS，你连接入口 IP，业务程序跑在 VPS 上，流量自动从出口 IP 发出。官方列举的适用任务很明确：在 VPS 里访问后台、调用授权 API、上传文件、进行客户端测试。对应到实际业务，跨境电商店铺运营、直播推流、素材上传、企业管理后台这类“从国内向外发起访问”的场景是匹配的。

不适合的场景同样明确——出口不接受外部连入，所以**不能作为公开网站源站、支付回调接收端、邮件服务器或游戏服务端**。需要外部主动连入的业务，需要的是允许公网入站的服务，这类需求在这条线路上跑不通。公开建站需求建议直接看带公网入站的常规 VPS 或其他产品形态。

还有两类“别碰”来自合规侧：所有产品需中国身份信息实名，禁止 VPN、机场、回国等违法违规用途，发现即清退不退款；产品默认无 SLA 保证，金融滑点改善、业务零中断这类承诺谁给不了，高可用需求应先通过工单确认服务边界，而不是默认独享带宽就等于高保障。

## 几个高频问题的直接回答

**不在深圳/广东，能用深港 IX 吗？** 可以。IX 不限连入省份，只要你的前置机在支持列表的云厂网络里。但官方也提醒：不能仅因人在深圳就认定适合 IX，前置条件才是第一道门槛。

**1~2ms 是我的全程延迟吗？** 不是。那是深圳到香港段内的参考值。你的实际耗时 = 本地到前置机 + 前置机到入口 + 端内 + 出口到目标，各段都要算。

**出口 IP 是原生 IP 吗？** 官方明确不保证原生、住宅或流媒体解锁属性，独享 IP 也不保证平台账号不被限制。

**能退款吗？** 只有 24 小时内的质量问题可申请，需要工单提交具体证据，审核通过才退。冲动下单前想清楚。
